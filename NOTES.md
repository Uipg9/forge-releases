- **Fixes the "EBUSY ... fabric-carpet" stop for real.** The cause: a stopped test leaves its game server (java) running on Windows, which keeps holding the helper jars, the world and the test port, so the next layer cannot replace them. Now every test run first ends any leftover java started from that mod's folder and anything still on the test port, ends the whole process tree on timeouts, and cleans up again when the server finishes. Copying helper jars retries and, if Windows still will not let go, the scenario carries on without the bot (the compatibility check is skipped) instead of stopping the mod.
